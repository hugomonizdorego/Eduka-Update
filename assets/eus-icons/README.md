# EUS state icons

| File | State |
| --- | --- |
| `eus-update-idle.png` | no update; normally hidden from the panel |
| `eus-update-available.png` | one or more updates are available |
| `eus-update-running.gif` | animated installation state |
| `eus-update-running.png` | static fallback for the running state |
| `eus-update-finished.png` | installation finished |
| `eus-i18n.json` | indicator translations |
| `eus-icons.json` | icon manifest |

The installed directory is `/usr/lib/EUS-ICONS` for compatibility with
Eduka-Panel.
