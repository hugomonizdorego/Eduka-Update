# Security Policy

## Supported version

Security fixes are applied to the latest EUS release. The currently supported
version is `0.14`.

## Reporting a vulnerability

Do not publish an exploitable issue in the public issue tracker. Contact the
Edukasaun OS maintainers through the official project channel at
<https://www.edukasaunos.tl/> and include:

- the affected EUS version;
- the operating-system version and desktop session;
- reproducible steps;
- the security impact; and
- a proposed fix, if available.

Never include passwords, authentication cookies, private repository URLs, or
other secrets in a report.
